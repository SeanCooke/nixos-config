# Contributing

> "What are you doing in my swamp?" - Shrek

This repo is intended to be the configuration of Sean Cooke's personal NixOS
laptop.  Any PR into this repo will be considered.  To raise a PR, follow the
steps below:

1. Fork the repo.
2. Make your changes and push changes to your fork.
3. Create a PR into
[nixos-config](https://github.com/SeanCooke/nixos-config/pulls) from your fork.
4. Sean will consider your PR and will either merge or give a reason why your
PR was not merged.

An example of a PR from an external user into this repo can be found
[here](https://github.com/SeanCooke/nixos-config/pull/27).

Thank you for contributing to nixos-config!
